# Proposer un changement

Tout le monde peut proposer un changement, personne n'a besoin d'être invité.

1. Copiez le dépôt chez vous avec le bouton « Fork » de GitHub.
2. Créez une branche, faites votre changement, un sujet à la fois.
3. Vérifiez chez vous : `npm run build`, puis la page dans le navigateur. Si vous avez
   touché à un moteur, `npm run verifier` aussi, et `npm run verifier:exact` si la retouche
   ne doit rien changer aux règles.
4. Ouvrez une « pull request » vers la branche `main` de ce dépôt. Dites ce que ça change
   et comment vous l'avez vérifié.

Rien n'arrive sur walidai.fr tant que la proposition n'est pas relue et acceptée.

Pour un gros changement (une nouvelle ville, une nouvelle règle du modèle), ouvrez d'abord
une « issue » pour en parler : ça évite de travailler pour rien.

## Quelques règles

- Textes en français simple, au vouvoiement, sans jargon.
- Un modèle reste un modèle : pas de chiffre présenté comme une preuve, pas de texte qui
  se lit comme une consigne de terrain.
- Les données viennent de sources publiques, datées et citées. Pas de données personnelles.
- Les contributions sont proposées sous la licence du fichier concerné : MIT pour le code,
  ODbL pour les cartes dérivées d'OpenStreetMap.
